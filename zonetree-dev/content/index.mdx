<section class="zt-section zt-quickstart" aria-labelledby="zt-quickstart-title">
  <div class="zt-quickstart-copy">
    <p class="zt-eyebrow">FROM PACKAGE TO PERSISTENCE</p>
    <h2 id="zt-quickstart-title">A storage engine.<br/>A familiar API.</h2>
    <p>Open a tree, write a value, and read it back. Your data lives in a local directory, and your code stays in C#.</p>
    <div class="zt-install">

```sh
dotnet add package ZoneTree
```

    </div>
    <div class="zt-quickstart-links">
      <a class="zt-text-link" href="https://www.nuget.org/packages/ZoneTree/" target="_blank" rel="noopener">ZoneTree on NuGet <Icon name="tabler:arrow-up-right"/></a>
      <a class="zt-text-link" href="/docs/getting-started/">Follow the getting started guide <Icon name="tabler:arrow-right"/></a>
    </div>
  </div>
  <div class="zt-code-panel">
    <div class="zt-code-heading"><span><Icon name="tabler:code"/> Program.cs</span><span>C# / .NET</span></div>
    <Tabs group="home-code" selectedTab="read-write" ariaLabel="ZoneTree code examples" tone="neutral" variant="none">
      <TabPane id="read-write" label="Read &amp; write">

```csharp
using ZoneTree;

using var tree = new ZoneTreeFactory<int, string>()
    .SetDataDirectory("data/my-tree")
    .OpenOrCreate();
using var maintainer = tree.CreateMaintainer();

tree.Upsert(42, "Hello, ZoneTree");

if (tree.TryGet(42, out var value))
    Console.WriteLine(value);
```

      </TabPane>
      <TabPane id="range-scan" label="Scan a range">

```csharp
using ZoneTree;

using var tree = new ZoneTreeFactory<int, string>()
    .SetDataDirectory("data/my-tree")
    .OpenOrCreate();
using var maintainer = tree.CreateMaintainer();

using var iterator = tree.CreateIterator();
iterator.Seek(100);

while (iterator.Next() && iterator.CurrentKey < 200)
    Console.WriteLine($"{iterator.CurrentKey}: {iterator.CurrentValue}");
```

      </TabPane>
    </Tabs>
    <p class="zt-code-note">One tree per data directory. The maintainer handles background merges and cache cleanup.</p>
  </div>
</section>
