        <span>C# / .NET</span>
      </Flex>
      <div class="zt-docs-install">
```sh
dotnet add package ZoneTree
```
      </div>
      <div class="zt-docs-example-code">
```csharp
using ZoneTree;

using var tree = new ZoneTreeFactory<int, string>()
    .SetDataDirectory("data/my-tree")
    .OpenOrCreate();
using var maintainer = tree.CreateMaintainer();

tree.Upsert(42, "Hello ZoneTree");
if (tree.TryGet(42, out var value))
    Console.WriteLine(value);
```
      </div>
      <p class="zt-docs-example-note">
        Keep the maintainer alive with the tree to schedule background merges
        and clean inactive caches.
        <a href="/docs/usage/maintenance/"
          >Understand maintenance <Icon name="tabler:arrow-right"/></a>
