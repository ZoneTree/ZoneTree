        value.
      </p></Panel>
    <Panel tone="accent" variant="surface" class="p-0" bodyClass="p-4"
      ><strong>One-key decisions</strong>
      <p>
        Use atomic methods when the current value determines the accepted
        update.
      </p></Panel>
    <Panel class="p-0" bodyClass="p-4"
      ><strong>Related keys</strong>
      <p>
        Use a transaction when several keys in one tree must share a commit
        boundary.
      </p></Panel>
  </Grid>
